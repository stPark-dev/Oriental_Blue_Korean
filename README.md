## 📖 게임 소개

『오리엔탈블루 청의천외』는 2003년 닌텐도가 발매한 게임보이 어드밴스용 RPG입니다.
『천외마경(天外魔境)』 시리즈의 세계관을 바탕으로, 선택지에 따라 동료·스토리·결말이 갈리는
멀티 시나리오 구조와 한자 조합으로 기술을 만들어내는 독자적인 시스템이 특징입니다.

| 항목 | 내용 |
| --- | --- |
| 원제 | オリエンタルブルー 青の天外 |
| 플랫폼 | Game Boy Advance |
| 장르 | 롤플레잉 게임 (1인용) |
| 발매 | 2003년 / 닌텐도 |
| 언어 | 일본어 (해외 정식 발매 없음) |

> 해외에 정식 발매된 적이 없어 일본어 외의 언어로는 플레이할 수 없었던 작품입니다.
> 이 프로젝트는 그 장벽을 낮추는 것을 목표로 합니다.

## 💻 개발 환경

리눅스를 주 작업 환경으로 삼습니다. 툴은 전부 **파이썬 3.10+ 표준 라이브러리**로
동작하며, 폰트 생성에만 Pillow가 필요합니다. flips 같은 외부 ROM 해킹 유틸은
설치하지 않아도 됩니다 (IPS/BPS 생성·적용을 자체 구현).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp /경로/오리엔탈블루.gba rom/baserom.gba   # 본인이 덤프한 ROM
make check                                  # SHA-1 대조
make test                                   # 단위 테스트
make                                        # 사용 가능한 타깃 목록
```

| 툴 | 역할 |
| --- | --- |
| `tools/romcheck.py` | ROM 식별 · 무결성 확인 |
| `tools/scan.py` | 포인터 테이블 / Shift-JIS / 엔트로피 스캔 |
| `tools/gbalz.py` | GBA LZ77 · RLE 압축 해제 및 재압축 |
| `tools/tbl.py` | 코드-문자 대응 테이블(.tbl) 파서 |
| `tools/dumptext.py` | ROM → 번역용 텍스트 파일 |
| `tools/inserttext.py` | 번역문 재삽입 · 포인터 재작성 |
| `tools/charset.py` | 번역문에서 사용 문자 추출 |
| `tools/mkfont.py` | 한글 서브셋 비트맵 폰트 생성 |
| `tools/patch.py` | IPS / BPS 패치 생성 · 적용 |
| `tools/obtext.py` | 게임 고유 압축 해제 · 문자열 테이블 탐색 |
| `tools/obfont.py` | 원본 폰트 검증 · 글리프 추출 |
| `tests/` | `make test` — 단위 + ROM 회귀 테스트 24개 |
| `tools/dumpscript.py` | 스크립트 전체 덤프 (`make script`) |

자세한 작업 흐름은 [`docs/WORKFLOW.md`](docs/WORKFLOW.md)를 참고하세요.

## 🛠 패치 적용 방법

> 패치가 배포되기 전까지는 아래 절차를 사용할 수 없습니다.

1. 정품 카트리지에서 덤프한 일본판 ROM을 준비합니다.
2. 릴리스 페이지에서 배포되는 패치 파일(`.ips` / `.bps`)을 받습니다.
3. 패치 도구(예: [Flips](https://www.romhacking.net/utilities/1040/), [Lunar IPS](https://www.romhacking.net/utilities/240/))로 ROM에 패치를 적용합니다.
4. GBA 실기 또는 에뮬레이터(mGBA 등)에서 실행합니다.

**ROM 파일은 이 저장소에서 배포하지 않으며, 배포 요청도 받지 않습니다.**

## ⚖️ 저작권 안내

『오리엔탈블루 청의천외』의 모든 권리는 원 저작권자에게 있습니다.
본 프로젝트는 비영리 팬 번역이며, 원작의 게임 데이터(ROM, 리소스)는 포함하지 않습니다.
저장소에는 번역 결과물과 패치 제작에 필요한 코드·문서만을 포함합니다.

이 저장소에 포함된 이미지는 게임 소개 목적으로만 사용되었습니다.
권리자의 요청이 있을 경우 즉시 삭제하겠습니다.
