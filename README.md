## 📖 게임 소개

『오리엔탈블루 청의천외』는 2003년 닌텐도가 발매한 게임보이 어드밴스용 RPG입니다.
『천외마경(天外魔境)』 시리즈의 세계관을 바탕으로, 선택지에 따라 동료·스토리·결말이 갈리는
멀티 시나리오 구조와 한자 조합으로 기술을 만들어내는 독자적인 시스템이 특징입니다.

| 플랫폼 | Game Boy Advance |
| 장르 | 롤플레잉 게임 (1인용) |
| 발매 | 2003년 / 닌텐도 |
| 언어 | 일본어 (해외 정식 발매 없음) |

글자를 담는 스택 버퍼 8바이트뿐이라 한글 한 음절(5바이트)이 들어갑니다.

계산합니다 ([`docs/ROM_NOTES.md`](docs/ROM_NOTES.md) 참조).

쓰인 한글 음절 1,130자. 코드 공간은 11,172음절 전부를 담을 수 있어 **한도가 없습니다.**

## ⚙️ 작동 방식

이 게임은 텍스트를 **고유 압축 + 고유 문자 코드**로 저장하고, 글꼴도 압축 없이
ROM에 흩어 둡니다. 한글화의 핵심은 세 가지입니다.

**1. 문자 코드 공간** — 본문 렌더러는 `01`–`05` 이스케이프를 일반적으로 처리해
코드 `0x000`–`0x5FF`(1,536칸)를 씁니다. 한글은 8픽셀 칸 두 개를 쓰므로
음절 하나가 코드 두 개입니다.

```
앞 코드 = 초성×21 + 중성      399가지 (뱅크 3·4)
뒤 코드 = 종성                 28가지 (뱅크 5)
음절 번호 = 앞×28 + 뒤         11,172가지 전부
```

**2. 출력 훅** — 원본 폰트 배열은 코드당 글리프 하나뿐이라 음절 수가 제한됩니다.
그래서 글리프 인출 지점의 `bl` **대상 주소만** THUMB 훅으로 바꿉니다. 훅은 음절
번호로 색인 테이블을 찾아 16×16 글리프를 두 칸에 나눠 씁니다. 스트림 포인터가
살아 있어 앞뒤 코드를 모두 볼 수 있으므로 **RAM 을 한 바이트도 새로 쓰지
않습니다.** 기존 코드에서 고치는 것은 `bl` 세 개(12바이트)뿐입니다.

**3. 조합형은 기각했습니다** — 출력 경로가 비트맵을 OR 로 합치는데, 쓸 수 있는
폰트가 전부 완성형 디자인이라 자모가 깨끗하게 분리되지 않았습니다 (평균 오차
7픽셀). 근거와 측정치는 [`docs/ROM_NOTES.md`](docs/ROM_NOTES.md) 에 남겼습니다.

## 💻 개발 환경

리눅스를 주 작업 환경으로 삼습니다. 툴은 전부 **파이썬 3.10+ 표준 라이브러리**로
동작합니다. 글리프 렌더에 Pillow, 어셈블러 테스트에 capstone 이 필요합니다.
flips 같은 외부 ROM 해킹 유틸은 설치하지 않아도 됩니다 (IPS/BPS 자체 구현).
실기 확인에는 mGBA 를 씁니다 — AppImage 로 받으면 설치가 필요 없습니다.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp /경로/오리엔탈블루.gba rom/baserom.gba   # 본인이 덤프한 ROM
cp /경로/Galmuri14.ttf font/                # 본문용 16×16 (OFL, 저장소 미포함)
cp /경로/Galmuri7.ttf  font/                # 메뉴용 8×8 · 타이틀 부제

make check      # ROM SHA-1 대조
make test       # 테스트 175개
make script     # 원문 덤프 -> script/ja/
make insert     # 번역문 삽입 -> build/patched.gba
make width      # 창 밖으로 잘리는 줄 찾기
make flow       # 넘치는 줄 쪼개기 (GROW=8 WRITE=1 로 반영)
make audit      # 제어 코드·줄 수·printf·조사 전수 감사
make shiri      # 끝말잇기 낱말 사슬 검사
make patch      # 배포용 BPS
make            # 전체 타깃 목록
```

## 🛠 패치 적용 방법

> 패치가 배포되기 전까지는 아래 절차를 사용할 수 없습니다.

1. 정품 카트리지에서 덤프한 일본판 ROM을 준비합니다.
2. 릴리스 페이지에서 배포되는 패치 파일(`.ips` / `.bps`)을 받습니다.
3. 패치 도구(예: [Flips](https://www.romhacking.net/utilities/1040/), [Lunar IPS](https://www.romhacking.net/utilities/240/))로 ROM에 패치를 적용합니다.
4. GBA 실기 또는 에뮬레이터(mGBA 등)에서 실행합니다.

**ROM 파일은 이 저장소에서 배포하지 않으며, 배포 요청도 받지 않습니다.**

## ⚖️ 저작권 안내

『오리엔탈블루 청의천외』의 모든 권리는 원 저작권자에게 있습니다.
본 프로젝트는 비영리 팬 번역이며, 원작의 게임 데이터(ROM, 리소스)는 포함하지 않습니다.
저장소에는 번역 결과물과 패치 제작에 필요한 코드·문서만을 포함합니다.

이 저장소에 포함된 이미지는 게임 소개 목적으로만 사용되었습니다.
권리자의 요청이 있을 경우 즉시 삭제하겠습니다.
