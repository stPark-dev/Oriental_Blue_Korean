# 번역 이어받기 — 인계 메모

남은 번역을 다른 사람(또는 다른 도구)이 이어받을 때 읽는 문서입니다.
**여기 적힌 다섯 가지를 어기면 게임이 조용히 깨집니다.** 화면에서
바로 안 보이고 한참 뒤에 이상하게 나오므로, 반드시 검사를 돌리세요.

## 준비

```bash
cp <원본롬> rom/baserom.gba     # SHA-1 414cad1a… (make check 로 대조)
make script                     # 원문 덤프 -> script/ja/ (커밋 안 함)
make sheet                      # 작업 시트 -> build/sheet/ (커밋 안 함)
```

`script/ja/` 와 `build/` 는 롬 파생물이라 `.gitignore` 대상입니다.
저장소에 있는 것은 **번역문(`script/ko/`)과 도구뿐**입니다.

## 작업 방법

1. `build/sheet/tXXXX.md` 를 엽니다. 항목마다 원문, **줄별 한글 최대
   글자 수**, 그 문장에 든 아이템 이름의 확정 표기, 앞뒤 대사가 있습니다.
2. `script/ko/tXXXX.txt` 의 해당 항목 본문을 채웁니다. 비워 두면 삽입 때
   건너뛰므로(원문 유지) 부분 번역 상태로도 빌드됩니다.
3. 검사를 돌립니다 — **하나라도 오류가 나면 고치고 다시**.

```bash
make audit    # 제어 코드 · 줄 수 · printf · 조사 병기
make width    # 창 폭 초과 (표마다 원문 최대 줄 폭이 한계)
make flow     # 넘치는 줄 쪼개기 (GROW=8 WRITE=1 로 반영)
make gloss    # 아이템 이름 표기 일관성
make same     # 같은 원문이 다른 표에 있으면 알려 줍니다 (WRITE=1 로 채움)
make insert   # 빌드
```

## 어기면 깨지는 다섯 가지

### 1. 제어 코드는 개수·순서까지 원문과 같아야 합니다

`<$10>` `<$12>` `<$14>` `<$19>001` 같은 것들입니다. 하나 빠지면 메시지가
거기서 멈추거나 다음 대사와 뒤엉킵니다. **위치를 옮기지도 마세요.**

### 2. 줄 수가 줄면 안 됩니다

원문이 4줄이면 번역도 4줄이어야 합니다. 줄이 **줄면** 그 자리에 이전
화면의 글자가 그대로 남습니다. 늘어나는 것은 창 용량만 확인하면 됩니다
(원문에도 13줄짜리가 있습니다).

### 3. 창 폭 — 한글은 한 자에 2칸

| | 칸 |
| --- | --- |
| 한글 한 자 | 2 |
| 가나·한자·기호·전각공백 | 1 |
| 제어 코드 | 0 |

**한계는 표마다 다릅니다.** 원문은 그 창에 맞춰 쓰였으므로, 그 표의 원문이
실제로 쓴 가장 넓은 줄이 곧 창 폭입니다. 본문 표는 대개 **20칸**(160픽셀)
이고, 기호 없이 한글만이면 **10자**입니다. `make width` 가 표마다 계산합니다.

넘기면 화면 밖으로 잘립니다. 먼저 `make flow GROW=8` 로 넘치는 줄을
쪼개 보고, 그래도 안 되면 번역문을 줄입니다. `make flow` 는 글자를 한 자도
바꾸지 않고 **번역자가 잡아 둔 줄바꿈도 살립니다** — 넘치는 줄만 그 자리에서
여러 줄로 나눕니다.

### 4. 줄 끝 전각공백은 화면을 지우는 장치입니다

원문 줄 끝에 전각공백만 있는 줄이나 꼬리가 붙어 있으면 **개수까지 그대로**
옮기세요. 빠뜨리면 그 자리에 이전 글자가 남습니다.

### 5. `<$1F>` 뒤 printf 지정자는 한 글자도 바꾸지 마세요

`<$1F>s` `<$1F>-7d` 같은 것입니다. 바꾸면 엉뚱한 값이 찍히거나 튕깁니다.

## 조사 병기

이름이 들어가는 자리는 받침을 미리 알 수 없으므로 두 형태를 나란히 씁니다.
전각 괄호를 씁니다.

```
<$12>은（는）    <$14>을（를）    <$1F>s이（가）
<$12>와（과）    <$12>아（야）    <$1F>s（으）로
```

`make audit` 이 빠진 곳을 잡습니다.

## 표기

**아이템 이름표(`script/ko/tDE1AF8.txt`)가 기준입니다.** 소지품 화면에
뜨는 이름이므로 대사도 그 표기를 따라야 합니다. `make gloss` 가 어긋난
곳을 잡습니다.

문맥이 분명할 때 줄여 쓰는 것은 괜찮습니다 — 「귀신의 뿔」을 「뿔」로.
창 폭 제한 때문에 오히려 줄여야 할 때도 있습니다. 검사도 이건 넘깁니다.

고유명사는 이미 수백 개가 굳어 있습니다. 새로 만들기 전에 반드시 기존
번역을 찾아보세요.

```bash
grep -rn '찾을말' script/ko/
```

지금까지 갈렸다가 통일한 것: 카라호토 · 엄니왕 · 쿠룽 · 모켄 ·
빛의 문 · 보배조개.

## 번역하지 않는 것

`tools/koprog.py` 의 `EXCLUDED` 에 이유와 함께 적혀 있습니다.

| 표 | 이유 |
| --- | --- |
| DFBEE4 | 게임이 읽는 코드가 없는 낱말표 |
| DF9080 | 끝말잇기 조각 — `koshiri.py` 가 롬을 직접 고칩니다 |
| DF809C · DF8494 | ＣＡＳＴ · ＳＴＡＦＦ 자막 (제작진 실명) |
| DFEB94 외 5개 | 개발용 장면 라벨 (`E074 ニンジャ船にのる` 꼴) |
| 4670DC 외 6개 | 글이 아닌 자리 |
| 220020 외 15개 | 크기 접두 바이너리 블롭 — 문자열표가 아님 |

항목 단위로도 뺍니다 — 빈 자리(`0` `０`), 그리고 서식·기호만 있어 옮길
말이 없는 것(`<$1F>-7dＧ` `ＥＸＰ` `×`).

**DF3908 의 남은 168항목은 번역 대상이 아닙니다.** 대사가 아니라 이름
입력 화면의 가나 문자판(`あいうえお…`)과 구분선입니다. 실제 문자 선택
그리드는 롬 `0x08ADEC` · `0x08B142` 의 Shift-JIS 이진 표라 문자열표와
별개입니다. 한글 이름 입력으로 바꾸려면 그리드 재작성과 이름 버퍼 처리가
필요한 **역공학 과제**이지 번역이 아닙니다.

## ROM 용량

**ROM 이 거의 꽉 찼습니다.** 한글은 음절 하나가 코드 두 개라 원문보다
자리를 많이 먹습니다 (원문 펼친 크기의 약 1.8배).

`make insert` 마지막 줄의 **「남은 자유 공간」을 매번 보세요.**

| | |
| --- | --- |
| 지금 여유 | 99,846바이트 (원본 ROM 안) |
| ROM 크기 | 16,777,216바이트 — **늘리지 않았습니다** |
| 남은 1,617항목 예상 순증 | 약 80,000바이트 |

압축을 넣은 뒤로는 `tools/inserttext.py` 의 ROM 확장이 **필요하지
않습니다.** 원본 16MB 안에 다 들어갑니다. 확장 기능은 남겨 두었으니
나중에 정말 모자라면 그때 씁니다.

다 채워도 들어가지만 여유가 크지 않습니다. 「자유 공간 부족」이 뜨면
번역이 잘못된 게 아니라 ROM 이 찬 것입니다 — 그 메시지의 숫자는 **처음
실패한 문자열 하나**의 크기일 뿐, 실제 부족분이 아닙니다.

삽입 문자열은 `tools/kolz.py` 가 게임 LZ 형식으로 눌러 넣습니다. 누르지
않으면 지금도 31KB 가 모자랍니다. 압축한 항목은 전부 전개기로 되풀어
원본과 대조한 뒤에만 들어갑니다.

## 남은 일 — 창 폭 2,683줄

`make width` 가 **2,662줄**이 창 밖으로 나간다고 알려 줍니다.

`tools/koflow.py` 는 **줄바꿈 위치만 옮깁니다.** 그래서 고칠 수 있는 건
이미 다 고쳤고, 남은 2,107항목은 도구가 직접 이렇게 말합니다 —
「번역문 자체를 줄여야 합니다」. 한 줄에 단어 하나가 통째로 안 들어가는
자리라 **글을 줄이는 수밖에 없습니다.**

```bash
make width                 # 남은 줄 (좁게 넘친 것부터 보여 줍니다)
make flow                  # 쪼개서 되는 게 남았는지 먼저 확인
make fit COUNT=200         # 줄여야 할 문장 목록 (많이 나온 순)
```

`make fit` 은 **문장 단위**로 묶어 보여 줍니다. 같은 문장이 여러 표에
되풀이되므로 한 번 줄이면 나오는 곳마다 같이 고쳐집니다 — 2,662줄이
서로 다른 문장 1,484개입니다. 맨 위 몇 개만 고쳐도 수백 줄이 사라집니다.

줄인 문장은 `{"원래 줄": "줄인 줄"}` 꼴 JSON 으로 모아 넣습니다.

```bash
python3 tools/kofit.py apply 고침.json --dry   # 검사만
python3 tools/kofit.py apply 고침.json
```

`apply` 는 줄마다 **제어 코드·줄바꿈·줄 끝 전각공백·창 폭**을 검사하고,
걸린 것만 빼고 나머지를 넣습니다. 한 건 때문에 배치가 통째로 날아가지
않습니다.

줄일 때는 고유명사를 지우기보다 **조사·부사·지시어**를 먼저 덜어내세요.
「이 카라호토를 지키려 싸워」 → 「카라호토 지키려 싸워」. 아이템 이름은
`make gloss` 가 봅니다.

말투는 인물마다 다릅니다. 「하지만→허나」 같은 교체는 `kofit.py rules` 에
넣지 않았습니다 — 그 인물이 예스럽게 말하는지 보고 정하세요.
